# memo-wiki（社内メモWiki）

HTMLファイル1つをブラウザで開くだけで動く、チーム向けのメモ・手順書ツールです。
サーバー不要・インストール不要・外部通信なし。社内の共有フォルダを選べば、そのままチームで共有できます。

## 特長

- **ファイル1つ**：`memo-wiki.html` に HTML / CSS / JavaScript をすべて内包
- **外部通信なし**：CDN・外部ライブラリを使わず、CSP（Content Security Policy）で外への通信をブラウザ側で禁止
- **2つの保存先**：自分だけ（ブラウザ内の IndexedDB）／チーム共有（共有フォルダ。File System Access API）
- **普通のファイルで保存**：共有フォルダには メモ1件＝フォルダ1つ（`.md`・`images/`・`drawings/`・`作業チェック.json`）
- **本番作業向け**：`1. [ ] 手順` がチェックリストになり、時刻と名前を記録。記録をコピーして報告に使える
- **書きやすさ**：Markdown＋日本語の色指定（`{赤:文字}`・`:::黄 メモ`）、表のマス目エディタ、画像への書き込み、日付・時刻の入力、`@名前`・用語の候補（マスタ台帳）

## 使い方

1. `memo-wiki.html` をダウンロードして、Chrome か Edge で開く
2. そのまま書けば「💾 自分だけ」（このブラウザ内）に保存
3. チームで使うときは、保存先ボタン →「👥 チーム共有」→ 共有フォルダを選んで「許可」

最初から入っている「例」フォルダに、使い方・仕様書・例文・テンプレートがあります。

| 項目 | 内容 |
|---|---|

| 想定規模 | 数人〜10人程度 |
| 必要なもの | なし（サーバー・インストール・管理者権限は不要） |

## セキュリティ

- 外部への通信はしません。HTMLの先頭の CSP で、外部のスクリプト・画像・通信を禁止しています
- メモに外部URLの画像を書いても読み込まず、リンクとして表示します
- データの置き場所は、ブラウザ内（IndexedDB / localStorage）か、利用者が選んで許可したフォルダだけです
- メモの本文はエスケープしてから表示するので、本文に書いたスクリプトは実行されません
- ログインや権限管理の仕組みはありません。閲覧・編集できる人は共有フォルダのアクセス権で管理してください（🔒 ロックは「うっかり編集の防止」です）

## 制約

- 編集履歴は残りません（ゴミ箱・エクスポート・ファイルサーバーのバックアップで補ってください）
- 同じメモの同時編集は、保存時の警告のみで自動統合はしません
- 暗号化はしません。パスワードや個人情報は書かないでください

## バックアップ

「⋯」メニューの **エクスポート** で、メモ・画像・書き込み・作業チェックを1つのJSONにまとめて保存できます。**インポート** でそのまま戻せます。
